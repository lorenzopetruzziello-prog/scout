# Scout

Scout dell'attacco per la pallavolo, da telefono, tablet e PC. Segna gli attacchi avversari e quelli della tua squadra, poi ti dice cosa dire alle giocatrici: chi è pericolosa, dove difendere, dove attaccare, con il campo disegnato e una modalità a tutto schermo per il timeout. Funziona senza rete.

Istruzioni di installazione e uso: [LEGGIMI.md](LEGGIMI.md). La versione precedente è in [legacy/](legacy/).
